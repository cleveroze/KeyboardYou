# Keyboard You

Клавиатура для Android в стиле **Material You / Material 3 Expressive** с режимом **Liquid Glass**, офлайн-переводчиком, буфером обмена и отдельным приложением для настройки.

## Скачать

Готовый APK собирается автоматически: **[Releases → latest](https://github.com/cleveroze/KeyboardYou/releases/tag/latest)** → `KeyboardYou.apk` (Android 8.0+).

После установки откройте приложение и выполните два шага: включите клавиатуру и выберите её по умолчанию.

## Возможности

- **Цвета**: палитра из обоев (Monet, Android 12+) или свой цвет; светлая/тёмная тема.
- **5 стилей**: Material You, Expressive, Liquid Glass (полупрозрачное стекло с бликами и кантом, живые пятна на фоне, экспериментальное размытие под клавиатурой), AMOLED, Пастель.
- **11 форм** Material 3 (печенье, клевер, солнце, ромб, цветок…) для акцентных кнопок и всплывашек; клавиши **морфятся** в форму при нажатии.
- **Анимации**: пружинные нажатия, всплывающие буквы, ряд альтернатив по долгому нажатию, плавные переходы панелей, анимированный тулбар.
- **Шрифты**: Nunito, Rubik, Manrope, Comfortaa, Unbounded и др.; размер, высота клавиш, отступы.
- **Переводчик** (ML Kit, офлайн, 20 языков): перевод при наборе прямо в клавиатуре, вставка, перевод всего поля.
- **Буфер обмена**: история, закрепление, подсказка только что скопированного.
- **Ввод**: русская, английская и украинская раскладки, автоисправление и подсказки по словарям на 40 тыс. слов, которые учатся на ваших словах, режим «только строчные», автозаглавные, точка двойным пробелом, курсор свайпом по пробелу, эмодзи, панель редактирования.

## Сборка

```bash
./gradlew assembleRelease
```

Kotlin + Jetpack Compose, minSdk 26, targetSdk 35.

## Словари

Частотные словари в `app/src/main/assets/dict` построены на основе [FrequencyWords](https://github.com/hermitdave/FrequencyWords) (Hermit Dave, MIT / CC BY-SA 4.0).
